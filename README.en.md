# Link IM

基于 Netty + Spring Boot 的高性能 IM 服务端，采用自定义二进制协议与事件驱动架构，支持 TCP/WebSocket 双承载。内置登录认证、连接限流、协议校验等安全机制，编解码与业务逻辑解耦，易于扩展与二次开发。
